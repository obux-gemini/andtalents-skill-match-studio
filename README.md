# &TALENTS Skill Match Studio

Öffentliche Designvorschau für das Skill-Matching aus Kandidaten- und Recruiter-Perspektive.

Die Inhalte sind Beispieldaten. Scores sind illustrativ. Die Buttons lösen keine echten Bewerbungen oder Entscheidungen aus.

Diese Website enthält ausschließlich statische Dateien und benötigt keine Installation. GitHub Pages veröffentlicht den Root-Ordner des Branches `main`.

Die Farbpalette wird nur im jeweiligen Browser gespeichert.
